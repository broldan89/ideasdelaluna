# Ideas de la Luna

Sitio web e imprenta con cotizador online, hecho con [Astro](https://astro.build) + Tailwind + Supabase.

## Desarrollo

```sh
npm install
npm run dev
```

Necesitás un archivo `.env` en la raíz con:
PUBLIC_SUPABASE_URL=...
PUBLIC_SUPABASE_ANON_KEY=...

## Build

```sh
npm run build
```
